## Структура
- `team/` — 7 персональных папок и 7 MATLAB-функций;
- `simulate_uav.m` — интеграция подсистем и общая динамика БПЛА;
- `config_uav.m` — настройки;
- `run_project.m` — точка запуска;
- `build_simulink_model.m` — обзорная архитектурная схема Simulink;
- `tests/run_tests.m` — проверки;
- `docs/` — интерфейсы, архитектура, схема.

## Запуск в MATLAB

Откройте корень проекта как Current Folder:

```matlab
run_project
```

Тесты:

```matlab
run('tests/run_tests.m')
```

Обзорная модель Simulink:

```matlab
build_simulink_model
```

Схема Simulink **обзорная**; математический расчёт учебной миссии выполняют MATLAB-функции.
