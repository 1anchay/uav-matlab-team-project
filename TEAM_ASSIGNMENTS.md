## Правила ответственности

- Каждый редактирует в первую очередь собственный `subsystem_*.m` и `README.md` в именной папке.
- Общие файлы (`simulate_uav.m`, `config_uav.m`, `setup_paths.m`, `run_project.m`, `build_simulink_model.m`) и контракты в `docs/INTERFACES.md` изменяют через Pull Request с согласованием затронутых участников.
- Перед объединением изменений в `main` необходимо запустить `run_project` и `run('tests/run_tests.m')`.
- Персональные ветки №01–05 существуют исторически; их имена сохранены, чтобы не ломать уже настроенную работу. Ветки №06–07 предназначены для новых участников.

**Важно:** публичный GitHub-репозиторий доступен для чтения всем, но право `Write` выдаётся отдельно по GitHub-username. Имена на скриншотах не являются проверенными логинами GitHub. См. [GITHUB_SETUP.md](GITHUB_SETUP.md).
