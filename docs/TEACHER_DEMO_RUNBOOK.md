# Инструкция демонстрации для преподавателя

**Цель:** показать самостоятельную работу всех 7 участников,
подтверждённые испытания и границу между проверенным кодом и новой V3.

## 1. Проверенная часть (Advanced MATLAB V2)

В корневой папке репозитория:

```matlab
run('tests/run_tests.m')
run('tests/run_advanced_tests.m')
run('tests/run_advanced_campaign_tests.m')
r = run_advanced_mission('unexpected',true);
```

**Из предыдущего подтверждённого запуска:** Advanced 13/13 PASS,
кампания 6/6 PASS, при неожиданном круге 1 replan, 23.10 с,
0.13 м до цели, 9.39 м до границы препятствия. Это исторические
измеренные показатели; при следующем запуске цифры следует сверить.

Скриншот 1: общий маршрут, оранжевый момент пересчёта, графики
навигации, скорости, батареи, расстояния и радиообмена.

## 3. Репрезентативность эксперимента

```matlab
study = run_robustness_study(10,true, ...
    {'unexpected','two_unknown'},[0 0.15 0.35]);
export_robustness_report(study)
```

Это **60 экспериментов** с различными seed и вероятностями
пропуска синтетического обнаружения. Они могут завершиться
ошибкой маршрута либо столкновением; такие случаи надо
оставить в CSV и объяснить. Не выдавать долю успехов за
доказательство безопасности физического БПЛА.

## 5. Сохранение доказательств

```matlab
run_defense_showcase(false)
```

Файлы появятся в `results/defense/`: две PNG-иллюстрации и
`DEMONSTRATION_SUMMARY.md`. Для нового V3 после прохождения
тестов можно вызвать `run_defense_showcase(true)`.
CSV/Markdown V2 хранятся отдельно в `results/v2/unexpected/`.

Поскольку эти файлы локально исключены из Git, выберите финальные
снимки/CSV и **осознанно** скопируйте их в `docs/evidence/`,
после чего зафиксируйте в GitHub. Не включайте чужие персональные
данные или учётные записи в скриншоты.
