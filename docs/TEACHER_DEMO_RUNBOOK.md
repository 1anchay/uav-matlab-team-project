## 5. Сохранение доказательств

```matlab
run_defense_showcase(false)
```

Файлы появятся в `results/defense/`: две PNG-иллюстрации и
`DEMONSTRATION_SUMMARY.md`. Для нового V3 после прохождения
тестов можно вызвать `run_defense_showcase(true)`.
CSV/Markdown V2 хранятся отдельно в `results/v2/unexpected/`.

Поскольку эти файлы локально исключены из Git, выберите финальные
снимки/CSV и **осознанно** скопируйте их в `docs/evidence/`,
после чего зафиксируйте в GitHub. Не включайте чужие персональные
данные или учётные записи в скриншоты.
