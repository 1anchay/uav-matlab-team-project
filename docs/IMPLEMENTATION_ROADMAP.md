# Пошаговое развитие UAV MATLAB / Simulink (7 участников)

## Этап 0. Контрольная точка
- `checkpoint/matlab-simulink-smoke-passed-20261123` хранит код, на котором команда получила 11/11 MATLAB-проверок и успешный smoke test архитектуры в MATLAB Online.
- Сгенерированные пользователем `.slx` находятся локально в MATLAB Drive; этот Git-коммит их **не содержит**.
- Базовую MATLAB-симуляцию `run_project` и существующие модели `UAV_*.slx` не изменяем и не перезаписываем.

## Этап 1. Понятная независимая архитектура
- Семь подсистем и отдельная общая Dynamics.
- Каждая подсистема — самостоятельная исполняемая модель `UAVF_*.slx` в `models/functional/generated/`.
- Читаемые имена блоков и линий, сверху управление, снизу диагностика; без переписывания прежних генераторов.

## Этап 2. Исполняемый функциональный прототип
- Новая **упрощённая двумерная** симуляция, не идентичная имеющейся MATLAB 3D-схеме.
- Внутри Model Reference — действующие MATLAB Function-блоки (не `InterfacePlaceholder`).
- Навигация: оценка [x,y,vx,vy]; управление: PD-регулятор; планирование: переключение waypoint из MATLAB-маршрута; обнаружение: расстояние до окружностей; безопасность: коррекция ускорения; энергетика: расход батареи; наземная станция: телеметрия.
- Общая динамика: дискретная модель положения, скорости, заряда с Unit Delay в контуре обратной связи.
- Входной маршрут вычисляет существующая MATLAB-функция планирования **перед** запуском Simulink. Не выдаём это за полноценное онлайн-планирование внутри Simulink.
- В модели нет двигателя, аэродинамики, полноценного GPS, IMU и 3D-кинематики. Это **учебный прототип**, не система управления физическим БПЛА.

## Этап 3. Верификация и материалы к защите
- Отдельный MATLAB/Simulink тест `tests/run_functional_simulink_tests.m` — компиляция, корректность интерфейсов, численные ограничения и результат миссии.
- Скрипт `models/functional/run_functional_demo.m` — удобный запуск, телеметрия, график, статус.
- В `docs/DEFENSE_GUIDE.md`: презентационный сценарий и честные ограничения модели.
- Новые `.slx` создаются только при выполнении генератора в MATLAB Online; до реального выполнения нельзя считать их проверенными.

## Критерии принятия
1. Старый `run('tests/run_tests.m')` по-прежнему проходит.
2. `run('tests/run_simulink_smoke_tests.m')` по-прежнему проходит.
3. Новая `build_functional_simulink_model` создаёт 8 отдельных исполняемых Model Reference + верхний уровень.
4. Новая `run('tests/run_functional_simulink_tests.m')` проходит на MATLAB Online.
5. У команды есть сохранённый вывод тестов, скриншот работающей модели и графиков.
