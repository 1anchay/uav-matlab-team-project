# Модуль 02 — Управление полётом

**Ответственный по утверждённой схеме:** Иван Живоглядов  
**Рабочая ветка:** `team/ivan-flight-control`  
**MATLAB-файл:** [`subsystem_flight_control.m`](subsystem_flight_control.m)

## Назначение

Управление полётом. Модуль независимо реализуется и проверяется как часть семимодульной архитектуры БПЛА.

## Интерфейс

- **Вход:** `nav`, `targetWaypoint [1x3]`, `cfg`.
- **Выход:** `control.acceleration [1x3]`, `yawRate`, `desiredVelocity`, `distanceToTarget`.
- Общие единицы и поля описаны в [контрактах интерфейсов](../../docs/INTERFACES.md).

## Текущая реализация

Каскадный P-регулятор с ограничением желаемой скорости по оценке тормозного пути; насыщение ускорения и скорости поворота.

## Как проверить

В корне репозитория в MATLAB:

```matlab
run('tests/run_tests.m')
run_project
```

Проверки, относящиеся к модулю: пределы `maxAccel` и `maxYawRate`; вблизи waypoint желаемая скорость меньше.

## Ограничения модели

Это упрощённый точечный движущийся объект без модели крена, тангажа и двигателя.

## Правило командной работы

Работай в своей ветке и данной папке. Изменения общих файлов и интерфейсов описывай в Pull Request. Не редактируй чужие модули без согласования. Сгенерированные Simulink-файлы `models/generated/*.slx` пока являются **архитектурными заглушками**; поведение БПЛА реализовано MATLAB-функциями.

**Примечание:** технические изменения подготовлены в общей ветке улучшений и не означают, что каждый участник уже лично выполнил или проверил соответствующий код.
