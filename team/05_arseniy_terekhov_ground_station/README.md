# Участник 5 — Арсений Терехов
## Подсистема связи, мониторинга и наземного управления

**Рабочий файл:** `subsystem_ground_station.m`

### Задача
Сформировать телеметрию, имитировать канал связи и подготовить данные для оператора/наземной станции.

### Вход
- навигация `nav`;
- состояние аппарата `state`;
- команды управления `control`;
- номер текущего waypoint;
- обнаруженные объекты;
- параметры связи из `cfg`.

### Выход
Телеметрический пакет `packet`: положение, высота, скорость, курс, батарея, waypoint, связь и обнаруженные объекты.

### Что уже есть
Формирование телеметрии и имитация потерь пакетов.

### Что сделать участнику
1. Добавить статус миссии/режим полёта в телеметрию.
2. Сделать предупреждение при низком заряде или плохой связи.
3. Подготовить простой вывод наземной станции: ключевые параметры в консоль/график.
4. При желании добавить команду оператора `HOLD` или `RETURN_HOME` как расширение.

### Критерий готовности
Пакеты формируются на каждом шаге, а потеря связи не ломает основную симуляцию.
