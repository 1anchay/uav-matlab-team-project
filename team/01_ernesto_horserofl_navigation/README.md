# Участник 1 — Ernesto Horserofl
## Подсистема навигации и ориентирования

**Рабочий файл:** `subsystem_navigation.m`

### Задача
Давать остальным подсистемам оценку текущего состояния БПЛА: координаты, высоту, скорость и курс.

### Вход
- истинное состояние виртуального БПЛА (`state`);
- настройки датчиков и шумов (`cfg`).

### Выход
Структура `nav`:
- `position = [x y z]`;
- `velocity = [vx vy vz]`;
- `speed`;
- `yaw`;
- при дальнейшем развитии — качество/достоверность навигационной оценки.

### Что уже есть
Имитация GPS/ГЛОНАСС, IMU и компаса с ошибками измерения.

### Что сделать участнику
1. Разобраться с текущей функцией и подписать основные строки комментариями.
2. Добавить сглаживание навигационных измерений или простую фильтрацию.
3. Проверить, что при шуме координат БПЛА всё равно достигает цели.
4. Не менять интерфейс `nav` без согласования с командой.

### Критерий готовности
`run_project` запускается без ошибок, а навигационные данные остаются конечными (`NaN/Inf` отсутствуют).
