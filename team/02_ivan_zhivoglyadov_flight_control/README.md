# Участник 2 — Иван Живоглядов
## Подсистема управления полётом

**Рабочий файл:** `subsystem_flight_control.m`

### Задача
По навигационным данным и очередной контрольной точке формировать безопасные команды движения БПЛА.

### Вход
- структура `nav` от навигации;
- `target = [x y z]` от планировщика маршрута;
- ограничения аппарата из `cfg`.

### Выход
Структура `control`:
- ускорение/команда движения;
- скорость изменения курса;
- дополнительные управляющие величины при развитии модели.

### Что уже есть
Простая P-логика движения к waypoint, ограничения ускорения, скорости и скорости изменения курса.

### Что сделать участнику
1. Разобраться с регулятором и коэффициентами.
2. Сделать отдельное управление высотой и курсом более плавным.
3. Проверить соблюдение ограничений `maxAccel`, `maxSpeed`, `maxYawRate`.
4. Подготовить короткое объяснение: «вход → закон управления → выход».

### Критерий готовности
БПЛА не входит в колебания, не превышает ограничения и достигает конечной точки.
