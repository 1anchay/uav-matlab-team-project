# Участник 3 — Бодя Лемченко
## Подсистема построения маршрута и планирования полёта

**Рабочий файл:** `subsystem_route_planning.m`

### Задача
Построить безопасный маршрут A → B и сформировать контрольные точки для подсистемы управления.

### Вход
- начальная точка;
- конечная точка;
- список препятствий;
- безопасный зазор и параметры маршрута из `cfg`.

### Выход
Матрица `route`, где каждая строка — waypoint `[x y z]`.

### Что уже есть
Обход круговых препятствий, построение промежуточных точек и удаление лишних waypoint'ов.

### Что сделать участнику
1. Понять алгоритм проверки безопасного отрезка.
2. Добавить оптимизацию длины маршрута или более удачный выбор обхода препятствия.
3. Проверить несколько наборов препятствий.
4. Убедиться, что первая точка — старт, последняя — цель.

### Критерий готовности
Все сегменты маршрута имеют безопасный зазор, а путь не содержит лишних точек.
