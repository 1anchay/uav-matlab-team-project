# Модуль 07 — Энергосистема и батарея

**Ответственный по утверждённой схеме:** Иван Касимов  
**Рабочая ветка:** `team/ivan-kasimov-energy`  
**MATLAB-файл:** [`subsystem_energy.m`](subsystem_energy.m)

## Назначение

Энергосистема и батарея. Модуль независимо реализуется и проверяется как часть семимодульной архитектуры БПЛА.

## Интерфейс

- **Вход:** `state`, `cfg`, опционально `control`.
- **Выход:** `energy.currentBattery`, `nextBattery`, `drainRate`, `estimatedRemainingSeconds`, `lowBattery`, `criticalBattery`.
- Общие единицы и поля описаны в [контрактах интерфейсов](../../docs/INTERFACES.md).

## Текущая реализация

Учебная оценка расхода по скорости, ускорению и вертикальному движению; прогноз до критического порога заряда.

## Как проверить

В корне репозитория в MATLAB:

```matlab
run('tests/run_tests.m')
run_project
```

Проверки, относящиеся к модулю: заряд убывает, не становится отрицательным, ускорение не снижает расход, критический порог срабатывает.

## Ограничения модели

Проценты не заменяют электрохимическую модель: не учитываются напряжение, температура, мощность, деградация.

## Правило командной работы

Работай в своей ветке и данной папке. Изменения общих файлов и интерфейсов описывай в Pull Request. Не редактируй чужие модули без согласования. Сгенерированные Simulink-файлы `models/generated/*.slx` пока являются **архитектурными заглушками**; поведение БПЛА реализовано MATLAB-функциями.

**Примечание:** технические изменения подготовлены в общей ветке улучшений и не означают, что каждый участник уже лично выполнил или проверил соответствующий код.
