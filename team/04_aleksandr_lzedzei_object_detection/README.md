# Участник 4 — Александр Лзедзей
## Подсистема обнаружения и распознавания объектов

**Рабочий файл:** `subsystem_object_detection.m`

### Задача
Имитировать камеру/датчик БПЛА: находить ближайшие препятствия и сообщать их положение относительно аппарата.

### Вход
- навигационная оценка `nav`;
- список объектов/препятствий;
- дальность сенсора и параметры из `cfg`.

### Выход
Массив `detections` с данными об обнаруженных объектах: расстояние, направление, тип/опасность.

### Что уже есть
Обнаружение объектов в заданном радиусе и расчёт относительного положения.

### Что сделать участнику
1. Добавить понятное поле `type`/`class` для объекта.
2. Добавить `confidence` или небольшую ошибку измерения.
3. Проверить ситуацию: объект вне дальности / объект рядом / несколько объектов.
4. Не передавать в планировщик «идеальные» данные, если включён шум сенсора.

### Критерий готовности
Объекты корректно появляются и исчезают из detections в зависимости от расстояния.
