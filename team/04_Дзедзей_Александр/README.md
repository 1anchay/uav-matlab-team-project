# Модуль 04 — Обнаружение объектов

**Ответственный по утверждённой схеме:** Александр Дзедзей  
**Рабочая ветка:** `team/aleksandr-object-detection`  
**MATLAB-файл:** [`subsystem_object_detection.m`](subsystem_object_detection.m)

## Назначение

Обнаружение объектов. Модуль независимо реализуется и проверяется как часть семимодульной архитектуры БПЛА.

## Интерфейс

- **Вход:** `nav`, массив `obstacles`, `cfg`.
- **Выход:** `detections` с `relativeXY`, `distanceToBoundary`, `bearing`, `confidence`, `closingSpeed`, `timeToCollision`.
- Общие единицы и поля описаны в [контрактах интерфейсов](../../docs/INTERFACES.md).

## Текущая реализация

Имитация дальномера по известной сцене, оценка скорости сближения и времени до границы объекта.

## Как проверить

В корне репозитория в MATLAB:

```matlab
run('tests/run_tests.m')
run_project
```

Проверки, относящиеся к модулю: обнаружение объекта в дальности, положительная скорость сближения, конечный TTC, отсутствие обнаружений при ошибке навигации.

## Ограничения модели

Не используется реальная камера или нейросеть. TTC — оценка при постоянной текущей скорости, не строгая гарантия.

## Правило командной работы

Работай в своей ветке и данной папке. Изменения общих файлов и интерфейсов описывай в Pull Request. Не редактируй чужие модули без согласования. Сгенерированные Simulink-файлы `models/generated/*.slx` пока являются **архитектурными заглушками**; поведение БПЛА реализовано MATLAB-функциями.

**Примечание:** технические изменения подготовлены в общей ветке улучшений и не означают, что каждый участник уже лично выполнил или проверил соответствующий код.
